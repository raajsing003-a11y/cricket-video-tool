# Asli Chrome check list (C211) — apne PC par, 15-20 min

Kaise: GitHub Pages link Chrome (desktop) mein kholo -> Ctrl+Shift+R. Har item ke aage OK / FAIL likho aur FAIL ka screenshot lo.
Console errors: F12 -> Console (laal errors dekho).

## A. Studio basics
- [ ] 1. Studio kholo: 3 tab dikhein (Scenes, Editor, Audio), console mein laal error nahi.
- [ ] 2. Scenes tab: example JSON load karo, preview chale, ▶ play ho.
- [ ] 3. Scenes ka export (chhota, 8-10 scene): MP4 download ho, VLC/phone mein awaaz + video dono chalein.

## B. Scenes <-> Audio
- [ ] 4. Voice-over file daalo -> "🎛 Audio Editor mein enhance" -> Audio tab khule.
- [ ] 5. AI Enhance chalao (asli recording) -> awaaz saaf aaye, phir "↩ Scenes ko bhejo".
- [ ] 6. Scenes mein "voiceover ✨" dikhe; "↩ Purani audio" se wapas ho.
- [ ] 7. Ab Scenes export karo: nayi (enhanced) awaaz export mein aaye.

## C. Editor
- [ ] 8. Scenes clip Editor mein bhejo (➡ Editor mein bhejo) -> intro + scenes + outro chale.
- [ ] 9. Editor mein clip chuno -> "🎛 Audio" -> edit -> "↩ Video Editor ko bhejo" -> naya ✨ audio clip bane, original mute.
- [ ] 10. Editor export (MP4, AAC) -> file chale. 2-3 minute ka lamba export bhi ek baar.

## D. Extra
- [ ] 11. Whisper auto captions (Editor): chhoti Hindi clip par.
- [ ] 12. MediaPipe AI background (Editor): ek clip par.
- [ ] 13. Asli bumper (intro/outro) video files lagao, preview + export mein aayein.
- [ ] 14. Double-click audio segment -> "✂ Segment Edit" khule, Apply par ⏱ fit chale.
- [ ] 15. Audio Editor: Export format "AAC (M4A) 192k" -> .m4a file VLC/phone mein chale (awaaz saaf, poori length).
- [ ] 16. Audio Editor: SR "16000 Hz" + WAV export -> file chale, awaaz thodi dabi (normal).

## Result bhejne ka tareeka
Naye chat mein zip + ye likho: "Check: 1 OK, 2 OK, 5 FAIL (screenshot)..." — main sirf FAIL wale ek-ek karke theek karunga.

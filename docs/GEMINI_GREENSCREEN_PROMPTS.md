# Gemini: green-screen expression photos (presenter intro ke liye)

Gemini mein apni ek saaf photo reference ke taur par daalo, phir har expression ke liye ye BASE prompt + niche wali line (EXPRESSION) alag alag chalao.

## BASE prompt
Using the reference photo, create a photorealistic half-body image of the same person facing the camera, on a flat solid pure green (#00B140) chroma-key background with even lighting, no shadows, no gradients, no vignette. Keep the exact same face, facial features, skin tone, skin texture, hairstyle, beard and clothes as in the reference photo, with no face morphing, no beautifying and no distortion. His clothes and skin must not have any green reflection. Sharp, clean edges around hair, shoulders and hands. Head, shoulders and both hands fully inside the frame. Vertical 4:5, high resolution. No text, no logos, no props, no other people.

## EXPRESSION lines (ek ek karke)
1. Friendly warm smile, one hand raised in a casual hello wave.
2. Excited and laughing with open mouth, one hand pointing to the side as if showing something.
3. Serious news-anchor look, eyebrows slightly down, one hand gesturing while speaking.
4. Surprised, eyebrows raised, mouth slightly open, both palms open.
5. Thinking pose, one finger touching the chin, slight head tilt.
6. Confident smile with a thumbs-up.

## Tips
- Har baar wahi reference photo; kapde hare na hon (dark kapde best).
- Asli photo se chehra sabse sahi rehta hai: phone se hare kapde/chart ke saamne 6 photos khichna bhi chalega, tool wahi hara hata dega.
- Tool mein: Scenes > + Scene jodo > presenter > "+ photo" se sab expressions daalo.
- Style ke liye dusre creators ki images sirf inspiration hain; unka logo, handle, chehra ya caricature copy mat karna.

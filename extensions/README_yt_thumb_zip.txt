YT Thumbnail Bulk ZIP (Chrome extension)
Install: chrome://extensions -> Developer mode ON -> "Load unpacked" -> is folder ko chuno.
Use:
 1) Links paste karo (ek line mein ek) YA YouTube channel/search/playlist page par jaakar
    "Is tab ke saare video links lo" dabao (scroll count badha do to zyada videos aate hain).
 2) Quality chuno, "ZIP download karo" dabao. Sab thumbnails ek ZIP mein aate hain (01_ID.jpg, 02_ID.jpg ...).
Popup band mat karna jab tak ZIP save na ho jaye.

Title: har video ka title YouTube se aata hai. ZIP mein titles.csv (Excel) + titles.txt bante hain, aur 'File ke naam mein title' tick ho to image ka naam bhi 01_Title_ID.jpg hota hai. '📋 Sirf titles copy' se bina ZIP ke titles clipboard mein.

Titles ab alag Word file (yt_titles_DATE.docx) mein bhi save hote hain (ZIP ke saath dusri download). Chrome 'multiple downloads' ki permission puchhe to Allow karo. ZIP ke andar titles.csv bhi rehti hai.
